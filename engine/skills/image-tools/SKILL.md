---
name: image-tools
description: Generate, edit or combine images, make a batch, or search the built-in visual inspiration libraries.
---

Loading this skill enables the image plugin's original tools in this conversation. Use `generate_image` for one picture, `generate_images` for a batch, and `edit_image` for an existing image. The edit tool can use pictures attached to the current user message. For reference prompts, run `inspiration search <keywords>` through bash, then `inspiration show <source> <id>` for one full prompt. Keep image attachment results so the user sees the pictures in chat.

The user configures providers under Explore → Settings → Image Generation. If the plugin is disabled, it can be enabled in the app's plugin settings. For a selection in the web workbench, load `web-canvas`.
